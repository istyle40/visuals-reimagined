# Visuals Reimagined

A premium, responsive portfolio homepage for an AI photography studio. Built with Next.js, React, TypeScript, Tailwind CSS, Framer Motion, and Lucide icons.

## Live website

[https://istyle40.github.io/visuals-reimagined/](https://istyle40.github.io/visuals-reimagined/)

## Local preview

```bash
pnpm install
pnpm dev
```

Then open `http://127.0.0.1:3000`.

## Production build

```bash
pnpm build
```

The site is automatically published to GitHub Pages whenever changes are pushed to `main`.
